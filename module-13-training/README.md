# Модуль 13 - Цикл обучения

Учим модель. Собираем цикл обучения: прямой проход -> loss (cross-entropy) -> `zero_grad` -> backpropagation -> шаг оптимизатора (Adam) -> повтор.

## Что нового в этом модуле

- `train.py` - полный цикл обучения; loss падает от эпохи к эпохе.
- `config.py` - добавлен параметр `num_epochs`.

Обучение идёт на CPU и на маленьком тексте `cat_story.txt`, поэтому проходит быстро.

## Как запустить

```bash
cd module-13-training
python train.py
```

Ожидаемо: loss снижается с каждой эпохой (например, `10.41 -> 9.51 -> 8.59 ...`).

# Модуль 17 - Hugging Face: открываем настоящие модели

Своя модель написана и дообучена. Здесь мы впервые открываем чужие - и убеждаемся, что настоящая GPT-2 устроена так же: те же слои, те же роли, другие только числа. Заодно разбираемся, что лежит в репозитории модели, как управлять генерацией готовым методом, зачем нужна квантизация и как опубликовать свою модель в интернете.

## Что нового в этом модуле

- `hf_files.py` - что лежит в репозитории модели на Hugging Face. Скачиваем файлы GPT-2 по одному и считаем, почему файл весов весит 548 МБ, если параметров там на 497,8 МБ.
- `save_safetensors.py` - сохраняем свою модель в формате настоящих: веса в `chat_model.safetensors`, конфигурация в `simple_llm_config.json`. Формат безопаснее `.pth`: внутри только числа, исполнять нечего.
- `compare_gpt2.py` - наша модель и GPT-2 слой к слою. `wte` - это наша таблица токенов, `wpe` - таблица позиций, `c_attn` - склеенные Q, K и V. 6 534 528 параметров против 124 439 808 при одном и том же словаре.
- `hf_generate.py` - метод `generate()` со всеми параметрами и главная сверка модуля: наш `sample_next_token` из модуля 15 на логитах GPT-2 выдаёт ровно ту же последовательность, что библиотека.
- `hf_chat.py` - современная чат-модель `SmolLM2-135M-Instruct` и её шаблон разговора. Роли `system` / `user` / `assistant` превращаются в одну строку со спецтокенами, а остановка идёт по `<|im_end|>`: у этой модели свой EOS, но принцип тот же, что с `<|endoftext|>` в модуле 16.
- `quant_manual.py` - квантизация своими руками: делим на шаг, округляем, храним целое число и множитель. Наша модель худеет с 26,14 МБ до 6,95 МБ, и все 12 ответов остаются прежними.
- `quant_hf.py` - то же готовыми средствами: `dtype=` и `optimum-quanto`. Здесь же видно, что наивный замер памяти для квантованной модели врёт, и как посчитать честно.
- `publish.py` - собираем папку для публикации (веса, конфигурация и карточка модели с честным разделом про границы применимости) и выкладываем её на Hub.
- `load_from_hub.py` - скачиваем свою модель обратно с Hub и разговариваем с ней. Круг замкнулся.
- `test_hf.py` - тесты форматов, соответствия архитектур, сверки сэмплера, шаблона разговора, квантизации и публикации.

## Что понадобится дополнительно

К зависимостям курса добавляются два пакета, они есть в общем `requirements.txt`:

- `accelerate` - без него библиотека откажется загружать квантованную модель;
- `optimum-quanto` - собственно квантизация в `quant_hf.py`.

При первом запуске скачаются две модели, около 0,8 ГБ: GPT-2 (548 МБ) и SmolLM2-135M-Instruct (269 МБ). Второй запуск берёт их из кэша.

## Если весов нет

Веса в репозитории не хранятся: файлы по 26 МБ исключены в `.gitignore`. В чистой папке их создают заново те же скрипты, что в модулях 13-16, на процессоре это пара минут:

```bash
python train.py              # обучение с нуля на cat_story.txt, сохранит best_model.pth
python finetune.py           # дообучение на 12 парах «вопрос - ответ», сохранит chat_model.pth
python save_safetensors.py   # перевод в safetensors, сохранит chat_model.safetensors
```

Веса получатся другими, чем в уроках: обучение не повторяется до последнего бита. Ответы модели и размеры файлов совпадут, а числа, которые зависят от конкретных весов, например ошибка квантования в `quant_manual.py`, будут немного отличаться.

## Как запустить

```bash
cd module-17-hugging-face

# 0. Если весов ещё нет - обучение и дообучение из прошлых модулей
python train.py
python finetune.py

# 1. Что лежит в репозитории модели
python hf_files.py

# 2. Своя модель в формате настоящих
python save_safetensors.py

# 3. GPT-2 рядом с нашей моделью
python compare_gpt2.py

# 4. Генерация готовым методом и сверка с нашим сэмплером
python hf_generate.py

# 5. Разговор с чат-моделью
python hf_chat.py

# 6. Квантизация: руками и библиотекой
python quant_manual.py
python quant_hf.py

# 7. Публикация (нужен аккаунт и токен: hf auth login)
python publish.py
python load_from_hub.py

# Тесты
python -m pytest -q
```

`save_safetensors.py` требует `chat_model.pth` от `finetune.py`, а `quant_manual.py` и `publish.py` - результат `save_safetensors.py`. Тестам хватит одного `chat_model.pth`: недостающие файлы safetensors они создадут сами.

Для `publish.py` и `load_from_hub.py` впишите своё имя пользователя на Hugging Face в константу `REPO_ID` в обоих файлах. Без этого оба скрипта остановятся с подсказкой и в сеть не полезут.

# Модуль 16 - Дообучение: от продолжения текста к ответам

Базовая модель умеет только продолжать текст. Здесь мы берём её же веса и дообучаем (fine-tuning) на парах «вопрос - ответ»: модель учится не новым фактам, а новому поведению - отвечать коротко и вовремя замолкать.

## Что нового в этом модуле

- `qa_data.py` - 12 пар «вопрос - ответ» по рассказу про Барсика и шаблон промпта `Question: ...\nAnswer:`.
- `qa_dataset.py` - `QADataset`: вопрос и ответ кодируются вместе, но токены промпта закрываются меткой `-100`, поэтому loss считается только по ответу. В конце ответа - токен EOS, сигнал «я закончил».
- `finetune.py` - дообучение: загружаем `best_model.pth`, учим с меньшим learning rate (1e-4 против 3e-4 при обучении с нуля), сохраняем `chat_model.pth`.
- `chat.py` - диалог с дообученной моделью: генерация останавливается на EOS, а не по счётчику токенов.
- `demo_finetune.py` - одна модель до и после дообучения на одних и тех же вопросах.
- `demo_improve.py` - замер двух приёмов: аугментация формулировок и примеры отказа «I do not know».
- `test_finetune.py` - тесты формата данных и маскирования loss (модель для них не нужна).

## Как запустить

```bash
cd module-16-finetuning

# 1. Обучение с нуля (сохранит best_model.pth)
python train.py

# 2. Дообучение на парах «вопрос - ответ» (сохранит chat_model.pth)
python finetune.py

# 3. Диалог с моделью
python chat.py

# Демонстрации и тесты
python demo_finetune.py
python demo_improve.py
python -m pytest -q
```

`finetune.py` требует `best_model.pth` от `train.py` с тем же `max_length`, а `chat.py` и `demo_finetune.py` - `chat_model.pth` от `finetune.py`.

# Модуль 09 - Внимание с обучаемыми весами

Добавляем к вниманию обучаемые матрицы `W_Q`, `W_K`, `W_V` и каузальную маску - теперь модель может учиться, на что смотреть, и не подглядывает в будущее.

## Что нового в этом модуле

- `attention.py` - self-attention с обучаемыми весами (`nn.Linear` для Q/K/V) и каузальной маской.
- `demo_attention_trainable.py` - воспроизводит ручной пример из урока (числа совпадают до 4-го знака).
- `test_attention_weights.py` - первые тесты в курсе (формы, маскирование, сумма весов = 1).

## Как запустить

```bash
cd module-09-attention-weights
python demo_attention_trainable.py
python -m pytest -q
```

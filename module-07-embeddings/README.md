# Модуль 07 - Векторизация и позиции

Превращаем номера токенов в векторы. Модель учит смысл слов через токенные эмбеддинги и понимает порядок слов через позиционные эмбеддинги.

## Что нового в этом модуле

- `embedding.py`:
  - `TokenEmbedding` - вектор для каждого токена (`vocab_size = 50257` из `gpt2`);
  - `PositionalEmbedding` - вектор для каждой позиции;
  - `EmbeddingLayer` - складывает их вместе.
- `main.py` - показывает превращение формы `[batch, seq]` -> `[batch, seq, embed_dim]`.

Остальные файлы перешли из модуля 06 без изменений.

## Как запустить

```bash
cd module-07-embeddings
python main.py
```

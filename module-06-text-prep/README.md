# Модуль 06 - Подготовка текста

Первый код-модуль курса. Готовим данные для обучения: читаем текст, режем его скользящим окном на пары «вход - цель» и заворачиваем в `Dataset` и `DataLoader`.

## Что нового в этом модуле

- `config.py` - настройки проекта (`Config`): токенизатор `gpt2`, `max_length`, `stride`, `batch_size`.
- `tokenizer_utils.py` - получение токенизатора `gpt2` через `transformers`.
- `dataset.py` - класс датасета: скользящее окно превращает текст в пары `(x, y)`.
- `loader.py` - обёртка над `DataLoader` (батчи).
- `main.py` - демонстрация: печатает формы батчей `X` и `Y`.
- `cat_story.txt` - сквозной учебный текст курса.

## Как запустить

```bash
cd module-06-text-prep
python main.py
```

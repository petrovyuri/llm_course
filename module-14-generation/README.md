# Модуль 14 - Генерация текста

Финал основной части курса: настоящая GPT-архитектура в миниатюре. Обучаем модель с сохранением лучших весов и генерируем текст авторегрессионно - слово за словом.

## Что нового в этом модуле

- `train.py` - обучение сохраняет `best_model.pth`, `final_model.pth` и `model_config.json`.
- `generate.py` - авторегрессионная генерация: модель дописывает продолжение к промту (жадный выбор / argmax).

Число параметров модели - 6 532 736.

## Как запустить

```bash
cd module-14-generation

# 1. Обучаем и сохраняем веса
python train.py

# 2. Генерируем текст (нужен best_model.pth из шага 1)
python generate.py
```

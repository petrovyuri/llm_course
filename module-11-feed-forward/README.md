# Модуль 11 - Feed-Forward сеть

Добавляем позиционную полносвязную сеть (FFN): расширение `4 -> 8 -> 4` с нелинейностью. Внимание смешивает токены между собой, FFN обрабатывает каждый токен по отдельности.

## Что нового в этом модуле

- `feed_forward.py` - класс FFN (два `nn.Linear` с активацией между ними).
- `demo_ffn.py` - разбор на числах; `demo_reproduce_manual()` воспроизводит ручной пример.
- `test_ffn.py` - тесты форм и параметров.

## Как запустить

```bash
cd module-11-feed-forward
python demo_ffn.py
python -m pytest -q
```

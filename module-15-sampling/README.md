# Модуль 15 - Сэмплирование: управляем генерацией

Учим модель не всегда выбирать самое вероятное слово. Добавляем температуру, top-k и top-p (nucleus) - параметры, которые управляют разнообразием и связностью текста.

## Что нового в этом модуле

- `sampling.py`:
  - температура - «сглаживает» или «заостряет» распределение;
  - `filter_top_k` - оставляет k самых вероятных токенов;
  - `filter_top_p` - оставляет минимальное ядро токенов с суммарной вероятностью p;
  - `sample_next_token` - выбор следующего токена с учётом всех настроек.
- `generate.py` - обновлён под сэмплирование (исправлена потеря промта при обрезке контекста).
- `demo_sampling.py`, `demo_sampling_manual.py` - разбор влияния температуры / top-k / top-p на числах.
- `test_sampling.py` - тесты фильтров и сэмплирования.

## Как запустить

```bash
cd module-15-sampling

# Обучение (сохранит best_model.pth)
python train.py

# Генерация с сэмплированием
python generate.py

# Демонстрации и тесты
python demo_sampling.py
python -m pytest -q
```
